# Product Brief

## Product Name
Kanabot

## One-liner
Kanabot is a Minecraft-bot-as-a-service web platform where you can spawn helper bots into your minecraft servers easily.

## Target Users
- Minecraft players who wants...
  - help building & mining
  - assemble a bot army
  - build autonomous systems with bots
- Minecraft players aged 8~18

## Problem
- Punching trees, mining, and landscaping in Minecraft are boring and time-consuming. Let a bot take care of those tasks!

## Value Proposition
- Easy to deploy and configure
- Free to play

## MVP Scope
- Frontend
  - Deploy bot into Minecraft Server
  - Basic config
    - Server IP
    - Bot name
  - Chat box UI
- Backend
  - Bot manager service (manages all the bots)
  - Bot connection and lifecycle
  - Basic in-game bot commands using mineflayer GitHub Repo
    - follow master
    - guard master

## Out of Scope for MVP
- Frontend Auth
- Deploy project to AWS
- Online mode for bot
